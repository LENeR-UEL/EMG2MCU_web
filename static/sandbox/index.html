Sandbox

A notebook that runs the EMG2MCU pipeline in your browser. Generate a synthetic three-class EMG recording, configure the bandpass and notch filters, the onset detector, the windowing and the feature set, then train a Random Forest on the time-domain features and inspect the deployable biquad filter the pipeline would ship to the ESP32. Nothing is uploaded: Python runs on your machine.

Starting Python…

The first start downloads Python, scikit-learn and matplotlib (about 30 MB), which can take a minute; later visits use the browser cache.
